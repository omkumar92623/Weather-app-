#  Weather API

A simple Weather API project built using **Python and API Integration** that provides real-time weather information based on geographic coordinates.

##  About the Project

This project fetches weather information for a specific location using its geographical coordinates.

First, the user provides the **latitude and longitude** of a location. The application then uses API integration to retrieve weather data for those coordinates and displays the weather information.

##  Features

- Fetch weather information using latitude and longitude.
- API integration to retrieve real-time weather data.
- Get weather details for different geographical locations.
- Simple and easy-to-use API endpoints.

##  How It Works

1. The user provides the latitude and longitude of a location.
2. The application sends these coordinates to the weather API.
3. The external API processes the request and returns weather data.
4. The application displays the weather information.

##  Technologies Used

- **Python** – Backend programming language.
- **FastAPI** – Building API endpoints.
- **API Integration** – Fetching external weather data.
- **HTTP Requests** – Communicating with external APIs.

##  Project Objective

The main objective of this project is to understand how external API integration works, how to send geographical coordinates to an API, and how to retrieve and process real-time weather information using Python and FastAPI.
